# 原 Gamma 高還原靜態網站設計規格

## 1. 決策與目標

停止採用先前的深色「星空療癒重新詮釋」方向。新版以使用者原有的 [Gamma 頁面](https://parent-star-guide-1tpyu0y.gamma.site/) 為唯一視覺與文案母版，重建為可直接部署到 GitHub Pages 的靜態網站。

完成後，訪客應感覺自己仍在閱讀原 Gamma 頁：相同的標題、文案口吻、內容順序、明亮留白、橘綠按鈕與親子圖片節奏。技術層面則移除 Gamma 品牌、外部圖片依賴與原頁過大的空白，並保留大字與手機易讀性。

## 2. 還原原則

- 原頁文案逐段沿用，不重新改寫成抽象品牌文案。
- 原頁內容順序、圖片位置、方案價格與結尾金句維持一致。
- 採白色主背景、深灰文字、橘色重點與綠色 LINE 按鈕。
- 桌機保留原頁左右圖文配置；手機改為清楚的單欄閱讀順序。
- 原頁可取得的 AI 親子圖、指南示意圖與見證素材全部本機化。
- 移除 Gamma 的「Made with」標記、Gamma 導覽與不必要的展示外殼。
- 不複製 Gamma 的異常大空白、延遲造成的版面跳動或不利手機閱讀的尺寸。

## 3. 頁面內容順序

新版依下列順序呈現，標題與內文以原 Gamma 目前公開內容為準：

1. **首屏**：`《親子成長指南》看見孩子獨特的宇宙`、副標、橘色站內錨點按鈕、綠色 LINE 按鈕與星空親子圖。
2. **家長困惑**：情緒爆發、潛力未發揮、教養方式不適用、內心想法成謎，以及「不是你沒耐心，只是你沒拿到他的專屬說明書。」
3. **每個孩子都是獨特的**：父母與孩子的個性橋接、個別化解讀孩子的氣質與天賦、情緒管理與互動衝突策略。
4. **我們怎麼做的**：出生資料、占星分析、兒童心理學與生活實境的製作流程，以及專業團隊反覆琢磨的說明。
5. **需要提供的資料**：出生時間、出生地點、孩子姓名與選填的父母資料；保留原頁隱私說明。
6. **方案價格**：單一方案 `NT$3980`，包含一位孩子的完整分析報告與親子節奏互動解讀。
7. **你將得到什麼**：超過八千字 PDF、個人分析解讀、情緒節點解析、實用情境範例與關係節奏圖像。
8. **為什麼值這個價**：保留原頁五列產品比較表與「本指南」定位。
9. **指南帶來的轉變**：理解行為背後原因、掌握互動平衡點、有效溝通模式與家長引言。
10. **家長真實心聲**：保留三則原頁見證文字與可取得的原見證圖片。
11. **結尾行動區**：`一份屬於你與孩子的愛之地圖`、`懂，是比愛更深刻的慈悲。`、原結尾文案、親子宇宙圖與 LINE 按鈕。

現有網站自行新增的三種購買方案、五個 FAQ、深色品牌段落與固定底部 CTA 不出現在新版主流程。必要的隱私說明可保留在資料需求區或頁尾，但不得打斷原頁節奏。

## 4. 視覺設計

### 4.1 整體

- 主背景為白色或非常淡的暖白色，內容最大寬度約 1120–1200px。
- 大標使用柔和的繁中文字體優先序，例如 `Noto Sans TC`、`PingFang TC`、`Microsoft JhengHei`、sans-serif；不使用目前偏硬的英文字體作為中文字體主體。
- 桌機 H1 約 44–58px、H2 約 34–40px、內文約 18–20px；手機以流體尺寸縮放，但正文不得低於 18px。
- 文字主色接近原頁深灰黑；關鍵字使用珊瑚橘；按鈕分別使用珊瑚橘與清新綠。
- 按鈕為飽滿圓角膠囊形，保留原頁親切而直接的視覺語氣。
- 圖片使用中等圓角，不加入厚重玻璃效果、深藍卡片或過度星光裝飾。

### 4.2 首屏

- 桌機為左文右圖，左側約 52%、右側約 48%。
- 標題、副標與兩個按鈕沿用原頁排列；`不知道` 等原有強調字維持橘色。
- 橘色「《親子成長指南》是什麼？」捲動到下一個核心說明區；綠色「加入官方Line」開啟核准的 LINE 網址。
- 手機依序顯示標題、副標、按鈕、圖片；按鈕可換行但不可縮成小字。

### 4.3 中段與結尾

- 原頁圖文段落採左右交錯，不把每段都改成大量卡片。
- 四項困惑、三項價值、四項資料、四項交付與三項轉變可使用簡潔文字分組；留白與圖片共同形成節奏。
- 比較表在桌機維持表格，在手機轉為逐列可讀的卡片或橫向不溢出的語意區塊。
- 結尾以寬幅親子宇宙圖收束，再呈現金句、說明與 LINE CTA。

## 5. 圖片與資產

- 所有正式圖片儲存在 `assets/images/`，正式 HTML 不引用 `gamma.app` 或 `imgproxy.gamma.app`。
- 來源以 `https://cdn.gamma.app/akw6y74cp1iyxtt/` 下的使用者原 Gamma 素材為準。
- 至少本機化六張主要 AI 親子圖：星空親子、疲憊家長、親子星光、孩子探索、親子閱讀、宇宙花園。
- 原頁的指南示意長圖與三則見證圖片若可取得，也依原順序本機化；不得以新生成的陌生風格圖片替換。
- 圖片轉為 WebP，直式圖最大寬度約 960px，橫式圖最大寬度約 1400px，不放大來源。
- 每張圖片提供繁中 `alt`、固定 `width`／`height` 與適合人物臉部的 `object-position`。
- 首屏圖使用 `loading="eager"` 與 `fetchpriority="high"`；其餘圖片使用 `loading="lazy"` 與 `decoding="async"`。

若某張來源已失效，該位置保留原文與留白，不使用失效外部連結，也不臨時生成不同風格的替代圖。

## 7. 響應式與無障礙

- 768px 以下使用單欄；閱讀順序固定為標題／說明、圖片、補充清單或按鈕。
- 驗收寬度為 360、390、768、1024、1440px。
- 不設固定底部 CTA，避免遮住手機內容。
- 所有觸控按鈕至少約 44px 高，焦點樣式清楚，色彩對比可讀。
- 維持語意化標題順序、主要內容 landmark、跳至主要內容連結與 `prefers-reduced-motion` 相容性。
- 禁止水平溢出、人物臉部遭不合理裁切、文字壓圖或圖片造成明顯版面跳動。

## 8. 技術邊界與失敗處理

- 維持純 `index.html`、`styles.css` 與本機圖片，不加入框架或執行期 JavaScript。
- GitHub Pages workflow 繼續部署 repository 靜態內容，不新增伺服器或資料庫。
- 圖片失敗時，容器維持合理尺寸；文字、價格、LINE 與付款回報仍可操作。
- 若原頁圖片無法合法取得或轉檔，實作必須記錄該資產並使用純文字降級，不得留下外部 CDN 依賴。
