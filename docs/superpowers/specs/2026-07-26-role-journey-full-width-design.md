# 首頁角色區滿版修正設計

## 目標

依使用者提供的截圖，只調整首頁 `#role-journey`：

- 移除主標題上方的「讓理解繼續發生」小字。
- 暖色背景延伸至瀏覽器左右邊界，不再留下兩側不同色的空白。
- 三張角色卡、主標題、說明文字與品牌署名維持目前的集中寬度與內容。
- 手機版保留既有單欄卡片、左右安全留白與無橫向捲動行為。

## 實作方式

移除 `#role-journey .eyebrow` 標記。桌面版讓 `.section-shell.role-journey` 滿版，並以響應式 `padding-inline` 維持現有內容寬度；手機版沿用既有 section gutter，不擴張內容。

## 驗收

- `#role-journey` 不再包含 eyebrow 小字。
- 桌面寬度 769px 以上，角色區寬度為 100%，且不受全域 section max-width 限制。
- 卡片仍為三欄；768px 以下仍為單欄。
- 全站測試通過，其他頁面與首頁其他章節不變。
