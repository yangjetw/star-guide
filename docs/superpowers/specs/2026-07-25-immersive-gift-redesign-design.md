# 赫爾墨斯的小宇宙：沉浸星夜禮物網站重設規格

日期：2026-07-25  
狀態：視覺方向已核准，等待書面規格核准  
參考：原 Gamma 網站、目前 GitHub Pages 網站、`ui-ux-pro-max`

## 一、目標

將目前偏向固定尺寸手冊的網站，重設為具有品牌記憶、情緒張力與送禮轉換能力的靜態銷售網站。

核心策略為：

- 以「沉浸星夜旅程」建立品牌吸引力。
- 以「溫柔禮物工房」提供商品理解與購買清晰度。
- 先讓訪客感受到孩子的獨特與被理解的價值，再說明禮物內容、真實回饋與購買方式。
- 維持 GitHub Pages 靜態部署，不引入需要維護的後端或自動化服務。

## 二、內容保留原則

以下內容視為既有資產，實作時必須保留：

- `index.html`、`gift.html`、`navigator.html`、`refund.html` 現有可見文字。
- 目前 11 張本地圖片，包括三張家長真實心聲截圖。
- 現有 LINE、頁面導覽、購買與退款連結。
- 公司、聯絡方式、退款與紙本發票說明。
- 現有表單與兌換流程的公開邊界。

允許的調整：

- 重新安排首頁章節順序。
- 將同一主題的文字拆分或合併到不同視覺區塊。
- 調整標題斷行、段落寬度、卡片結構與圖片裁切。
- 為可讀性加入不改變原意的小型標籤，例如英文章節標籤。
- 將現有 emoji 改為 CSS 裝飾或 SVG 圖示，但不改變資訊意義。

未經再次確認不得：

- 刪除主要銷售內容或真實見證。
- 改變價格、商品內容、退款條件或法律資訊。
- 以新生成圖片取代現有圖片。
- 加入新的第三方追蹤、付款或自動化服務。

## 三、核准的視覺方向

### 3.1 核心概念

「B 的沉浸星夜外觀＋C 的銷售骨架」。

深色段落負責情緒、品牌與敘事；明亮段落負責商品理解、社會證明與購買決策。網站不再使用每章固定 800×600 的手冊頁。

### 3.2 色彩系統

- 星空底色：`#0D142C`
- 星空次色：`#1B2850`
- 暖米白背景：`#FBF5EC`
- 紙張白：`#FFFAF4`
- 深色文字：`#1B2038`
- 次要文字：`#6C6467`
- 主要行動色：`#FF7859`
- LINE／正向行動色：`#5DCC88`
- 星光金：`#E7BF77`

色彩比例：

- 55% 深藍星夜
- 35% 暖米白與紙張白
- 10% 珊瑚橘、綠色與星光金

不得將工具自動建議的高飽和紅、粉紅作為全站主色；這與已核准的星空療癒方向衝突。

### 3.3 字體與排版

- 中文展示字：`Noto Serif TC`，後備為 `Songti TC`、`PMingLiU`、serif。
- 中文內文與介面字：`Noto Sans TC`，後備為 `PingFang TC`、`Microsoft JhengHei`、sans-serif。
- 桌機首屏標題約 64–96px；手機約 46–56px。
- 一般內文不得小於 16px；桌機主要說明以 18–20px 為主。
- 正文行高 1.7–1.95。
- 長文寬度限制於約 32–38 個中文字，避免跨越整個螢幕。

不使用過多粗體、全大寫或機械式置中。星空段落可使用較強對比，資訊段落以自然左對齊為主。

### 3.4 圖片處理

- 首屏圖片滿版或接近滿版，使用漸層遮罩確保文字可讀。
- 關鍵情緒圖片採大幅、不對稱或局部越界構圖。
- 指南預覽圖以商品主角方式呈現，不縮成普通小卡。
- 真實心聲截圖維持可辨識內容，使用輕微交錯、旋轉或紙張陰影，明確呈現其為真實對話。
- 圖片保留原始比例資訊，避免載入時版面跳動。
- 首屏圖片優先載入，其餘圖片延遲載入。

## 四、首頁故事架構

### 4.1 第一章：情緒鉤子

內容：

- 《親子成長指南》
- 看見孩子獨特的宇宙
- 每個父母都想給孩子最好，只是不知道什麼才是最好。
- 兩個既有行動按鈕

表現：

- 使用 `hero-parent-child.webp` 作為滿版星空主視覺。
- 深藍漸層遮罩由左向右減弱。
- 標題採大型中文襯線字。
- 導覽列置於星空內，使用半透明邊界與清楚的 LINE 行動。
- 首屏底部以三項簡短價值標籤銜接下一段。

### 4.2 第二章：送禮承諾

內容：

- 把這份理解，送給一個你在乎的家庭
- 既有送禮說明與入口

表現：

- 從深色星空自然轉入暖米白背景。
- 使用 `deliverables-reading.webp` 作為大幅拱形圖片。
- 加入小型紙張註記，強調「送進一個家庭的理解」。
- 這一段負責在首屏之後立刻說清楚商品屬性。

### 4.3 第三章：家長共鳴

內容：

- 你是否也有這些困惑？
- 四個既有困惑與說明

表現：

- 使用 `concerns-family.webp`。
- 不再使用四張大小相同的長方形卡片。
- 文字以兩至三個自然段落或錯落標籤呈現，保持可掃讀但不顯得像功能表。

### 4.4 第四章：個人化價值

內容：

- 每個孩子都是獨特的
- 父母與孩子的個性橋接
- 個別化解讀孩子的氣質與天賦
- 情緒管理與互動衝突策略

表現：

- 回到深色星夜。
- 使用 `guide-parent-child.webp` 與 `process-wonder.webp`。
- 以逐步揭露的故事方式呈現三項價值，不使用三張等寬白卡。

### 4.5 第五章：低摩擦流程

內容：

- 我們怎麼做的？
- 所需資料
- 隱私說明

表現：

- 合併目前分離的流程與資料章節。
- 使用 `required-data-family.webp`。
- 流程步驟保持完整，但降低卡片數量與視覺噪音。
- 隱私說明放在本章結尾，以柔和但高對比的安心提示呈現。

### 4.6 第六章：收到的內容

內容：

- 你將得到什麼？
- 超過八千字 PDF 電子指南
- 四項既有交付內容與後續說明

表現：

- 使用暖奶油色商品區。
- `guide-preview.webp` 為商品主角。
- `deliverables-reading.webp` 可作為情境輔助。
- 四項內容使用編輯式分欄或清楚的序列，而非四張相同卡片。

### 4.7 第七章：指南帶來的轉變

內容：

- 理解行為背後原因
- 掌握互動平衡點
- 有效溝通模式
- 既有引言

表現：

- 使用 `deliverables-reading.webp` 的局部，`closing-cosmos-family.webp` 保留給最終章。
- 以三個逐步變化的節點呈現，銜接真實心聲。

### 4.8 第八章：真實心聲

內容：

- 家長們的真實心聲
- 既有說明
- `testimonial-1.jpg`、`testimonial-2.jpg`、`testimonial-3.jpg`

表現：

- 使用溫暖金色或米黃色背景，與前後段形成清楚節點。
- 三張截圖保持足夠尺寸，使訪客能辨識其為真實對話。
- 桌機採交錯紙張式排列，手機採單欄完整展示。

### 4.9 第九章：價值與選擇

內容：

- 既有價值比較表。
- 送禮入口與價格方案連結。

表現：

- 將價值比較與購買決策集中。
- 桌機比較表保持完整；手機改為可理解的分組卡片或受控橫向表格，不得撐寬整頁。
- 主要行動指向 `gift.html`，LINE 為次要行動。

### 4.10 最終章：情緒收束

內容：

- 一份屬於你與孩子的愛之地圖
- 既有結尾文字與行動按鈕

表現：

- 使用 `closing-cosmos-family.webp` 滿版或寬幅背景。
- 回到深色星空，完成視覺閉環。
- 主要行動使用珊瑚橘，LINE 使用綠色。

## 五、共用頁面設計

### 5.1 `gift.html`

- 延續星空導覽與暖米白商品區。
- 三階方案使用一個主推薦方案與兩個次方案，不做三張完全相同的卡。
- 明確呈現購買者會收到什麼、如何轉送、兌換方式、紙本發票與客服。
- 真實心聲可在價格前後精簡重現，但不得複製成過長頁面。

### 5.2 `navigator.html`

- 定位為「已經收到祝福的人，下一步怎麼做」。
- 使用清楚的垂直步驟與單一主要行動。
- 保留表單與 LINE 邊界，不公開私人表單識別碼。
- 視覺比首頁更安靜，仍保留星空標題帶與品牌色。

### 5.3 `refund.html`

- 定位為可信任的政策頁。
- 使用高可讀性單欄內容、清楚標題與聯絡方式。
- 不使用沉浸式動畫或過度裝飾。
- 導覽、頁尾與按鈕樣式維持品牌一致。

## 六、響應式設計

檢查寬度：

- 375px
- 768px
- 1024px
- 1440px

手機規則：

- 不保留桌機的固定高度或滿版文字位置。
- 首屏圖片仍具情緒張力，但文字移至畫面下半部，避免遮住人物主體。
- 所有按鈕最小觸控高度 48px。
- 導覽精簡為品牌、主要入口與選單。
- 所有內容自然單欄重排。
- 真實截圖不得縮小到無法閱讀。
- 全站不得出現橫向頁面捲動。

## 七、動效

使用：

- 300–400ms 的小幅淡入。
- 圖片可使用非常輕微的景深或視差。
- 按鈕 hover 使用 150–220ms 的位移或色彩變化。
- 章節切換依靠背景色與留白，不依賴複雜動畫。

避免：

- 橫向捲動旅程。
- 大量彈跳。
- 快速縮放、旋轉或無意義的裝飾動畫。
- 初始將 SEO 內容設為不可見且沒有無 JavaScript 備援。

必須支援 `prefers-reduced-motion`。

## 八、可用性、效能與無障礙

- 文字對比至少符合 WCAG AA。
- 鍵盤焦點清楚可見。
- 所有互動元素可用鍵盤操作。
- 圖片保留準確替代文字。
- 外部連結保留安全屬性。
- 主要按鈕不得只靠顏色區分。
- WebP 圖片維持本地託管。
- 首屏以外圖片延遲載入。
- 不引入 GSAP、Three.js 或新的大型前端框架。
- 維持純 HTML/CSS；若需要淡入效果，只使用少量漸進增強 JavaScript。

## 九、測試與驗收

自動測試必須驗證：

- 四個公開頁面存在且語意結構正確。
- 所有既有可見文字仍然存在。
- 11 張圖片仍被使用。
- 三張真實心聲截圖仍存在。
- 表單識別碼與私人流程未被公開。
- LINE 與外部連結安全屬性正確。
- 無固定 800×600 手冊頁規則。
- 支援減少動效偏好。

瀏覽器驗收必須包含：

- 1440×900 桌機。
- 1280×720 小型桌機。
- 390×844 手機。
- 375×667 小型手機。
- 全站無橫向溢出。
- 首屏圖片正常載入，文字不遮擋主要人物。
- 每個章節文字完整可讀。
- 比較表在手機上不撐寬頁面。
- 真實心聲截圖在手機上可辨識。

視覺驗收標準：

- 首屏達到已核准高擬真稿的沉浸感。
- 深色與明亮章節交替有清楚節奏。
- 商品段落容易理解，不被過多裝飾干擾。
- 首頁不再呈現 17 張尺寸相同的手冊卡片。
- 整體感受為「值得送出的專屬禮物」，而不是一般教養文章或簡報。
