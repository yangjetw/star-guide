# 桌機閱讀字級與醒目導航列設計

## 目標

在不改變既有圖片、內容順序與編輯式版面風格的前提下，提高桌機閱讀性，並讓訪客一進站就能辨認頂部為主要導覽列。

## 核心方案

採用獨立深藍導航帶：

- 導覽列使用比首屏略亮的深藍表面色，與內容背景形成可辨識的層次。
- 加入低調的底部分隔線與陰影，不使用大量膠囊按鈕，維持品牌網站質感。
- 桌機導覽高度約 76px；品牌連結約 20px，功能連結約 17–18px。
- 「官方 LINE」保留主要操作地位，其他連結維持清楚但較克制的層級。
- 導覽列維持所有四個公開頁面一致，不新增 JavaScript 或複雜選單。

## 字級調整

- 桌機正文基準由最高 19px 提高至 20px。
- 眉題與章節標籤不得低於 16px；頁首眉題使用 17–18px。
- 卡片／事實清單內文提高至接近正文大小，不再使用小於正文 90% 的縮放。
- 流程編號、表格註記與見證說明等輔助資訊原則上不得低於 16px。
- 大標題維持現有尺寸上限，避免整體再次失衡。
- 手機正文維持至少 17px，導覽品牌與 LINE 按鈕保持可讀且不產生橫向溢位。

## 互動與無障礙

- 導覽連結保留清楚的鍵盤焦點狀態。
- 滑鼠移入時使用背景與文字顏色變化，不造成版面位移。
- 所有可點擊區域高度至少 44px。
- 深色導覽列上的文字維持足夠對比。

## 驗收標準

- 四個公開頁面使用相同導覽結構與同一版 CSS。
- 1280px 與寬螢幕下，導覽列可立即辨認且所有主要內文清楚可讀。
- 375px 手機版不產生橫向捲動，品牌名稱與 LINE 按鈕不互相擠壓。
- 自動測試鎖定導航高度、主要字級下限、快取版本及響應式規則。
- 實際瀏覽器檢查首頁、服務與退費頁及手機首屏。

## 不在本次範圍

- 不改寫文案。
- 不替換現有圖片。
- 不重排首頁章節。
- 不新增漢堡選單、動畫框架或 JavaScript。
