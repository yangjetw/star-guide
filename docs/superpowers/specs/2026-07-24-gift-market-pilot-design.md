# 禮物市場試營運網站設計規格

## 目標

將現有《親子成長指南》單頁網站改造成可供綠界審核、同時能測試禮物市場需求的四頁靜態網站。網站維持 GitHub Pages，不增加伺服器、資料庫、n8n、付費主機或自動化維護成本。

網站對外品牌為「赫爾墨斯的小宇宙」，法律主體為「星學會有限公司」（統一編號 69708677），公開客服信箱為 `astrokidsguide@gmail.com`，官方 LINE 為 `https://lin.ee/gMMpzNy`。

## 成功條件

- 正式網址可公開瀏覽，中文介面、價格以新臺幣標示。
- 每一頁皆能清楚辨認品牌、公司名稱、統一編號、客服信箱及官方 LINE。
- 首頁保留原 Gamma 的核心敘事、溫暖星空風格及既有 AI 圖像。
- 「家長們的真實心聲」使用原 Gamma 已公開的三張對話截圖，不以虛構文字取代。
- 購買頁以禮物情境為中心，清楚呈現 1、2、5 份方案與 10 份以上洽詢方式。
- 320px 以上手機寬度無水平溢出，主要文字不小於 18px，按鈕可觸控。
- 網站不宣稱尚未完成的電子發票、票券履約保障或自動化能力。
- 所有外部連結均使用 HTTPS，另開分頁並包含 `noopener noreferrer`。

## 網站架構

### 1. `index.html`：親子成長指南主頁

用途是建立理解、信任與價值感，不承擔完整交易說明。

保留現有書冊式視覺語言、八張本地星空親子圖及以下故事順序：

1. 看見孩子獨特的宇宙
2. 家長常見困惑
3. 每個孩子都不同
4. 指南製作方式
5. 所需資料與隱私
6. 會收到什麼
7. 價值比較與可能改變
8. 家長們的真實心聲
9. 前往送禮／洽詢

首頁價格只作簡潔導引，完整方案放在購買頁。主要行動為「把這份理解送給一個家庭」，次要行動為加入官方 LINE。

### 2. `gift.html`：禮物購買頁

頁首文案以「不是替父母決定答案，而是送他們一份理解孩子的起點」為核心。

固定方案：

- 1 份祝福：NT$3,980
- 2 份同行：NT$7,600
- 5 份分享：NT$17,900
- 10 份以上：透過官方 LINE 洽詢

每份包含：

- 一組 `STAR-XXXX-XXXX` 單次服務兌換碼
- 一張可由購買者自行透過 LINE 轉送的電子禮物卡
- 一份依收禮家庭資料製作的客製化 PDF《親子成長指南》
- 兌換與製作期間的官方 LINE／Email 協助

收禮者姓名與祝福文字為選填。禮物卡不顯示價格、付款資料、孩子資料或發放類型。

綠界票券服務尚未核准前，方案按鈕統一使用「洽詢購買」，連至官方 LINE，不放置可直接付款或匯款的入口。頁面以清楚但不干擾閱讀的文字說明「正式線上販售將於票券服務審核完成後開放」。

### 3. `navigator.html`：導航者課程頁

將原 Gamma「想成為導航者顧問」內容整理為獨立頁，與一般家長禮物商品清楚分流。頁面說明適合對象、學習內容與申請流程，行動按鈕連至既有「想成為導航者顧問」Google 表單或官方 LINE。

此頁不混入禮物方案價格，不宣稱招生名額、開課時間或證照效力。

### 4. `refund.html`：購買、兌換與退款政策

以一般使用者可理解的文字說明：

- 發行人及客服資料
- 付款確認與發票方式
- 電子禮物卡與 `STAR-` 兌換碼的交付方式
- 兌換碼不得公開張貼或重複使用
- 兌換碼本身不設定使用期限
- 尚未兌換、已兌換及已開始客製製作三種狀態的聯繫／退款處理原則
- 客製化數位內容開始製作前的確認程序
- 個人資料用途與聯絡方式

在票券履約保障方案核准以前，不刊登履約保證銀行、保管期間或核准字號。核准後再依綠界提供的正式文字補上，不自行編造。

截圖以三張卡片呈現；桌面為三欄或兩欄加一張置中，手機為單欄。保留截圖作為真實性證據，不把內容重新打成可任意修改的推薦文。

## 視覺系統

- 延續目前集中式精品書冊版型，而非重新做成散落卡片式銷售頁。
- 色彩維持深夜藍、奶油紙色、柔珊瑚及低飽和金色。
- 標題使用柔和中文襯線字體堆疊，內文使用系統黑體；不載入外部字型。
- 每一頁只有一個主要視覺焦點，內容寬度不超過 1080px，閱讀欄不超過 920px。
- 圖像具備描述性替代文字、固定寬高、延遲載入；首頁首圖除外。
- 手機版維持 18px 以上內文、52px 以上主要按鈕高度及單欄閱讀順序。

## 人工營運流程

第一階段完全人工：

1. 購買者透過官方 LINE 洽詢。
2. 票券服務核准後，依核准的收款方式付款。
3. 人工確認付款與發票。
4. 後台試算表配發一組 `STAR-XXXX-XXXX`。
5. 電子禮物卡寄給購買者，由購買者自行透過 LINE 轉送。
6. 收禮者填寫既有兌換表單。
7. 人工確認兌換、製作指南並交付 PDF。

免費品牌贈送與正式購買皆使用相同 `STAR-` 格式；差異只存於內部試算表的「發放類型」欄位。網站不公開兌換表單，只有持有禮物卡的人取得兌換入口。

## 明確排除

本次不製作：

- n8n 或 webhook
- 付款 API、綠界 API 或電子發票 API
- 自動產碼、自動寄信或自動產生指南
- 會員帳號、購物車、CRM 或預約排程
- 企業大量採購報價系統
- 網站內蒐集孩子出生資料
- 尚未核准的履約保障聲明

## 錯誤處理

- 外部表單或 LINE 無法開啟時，使用者仍可從頁尾取得客服 Email。
- 圖片載入失敗時保留替代文字，不讓關鍵流程只存在圖片中。
- 尚未核准票券服務時不顯示付款入口，避免形成無履約保障的付費票券交易。
- 兌換碼無效、已使用或重複送出時，由現有 Google 表單／試算表流程標記並引導聯絡客服；網站不承擔兌換驗證。

## 驗證

自動化測試須檢查：

- 四個 HTML 頁面存在且各有唯一 `h1`、主要內容地標及統一頁尾。
- 公司名稱、統編、客服 Email、LINE 及政策連結出現在必要頁面。
- 三階價格與 10 份以上洽詢文案正確。
- 不含 `n8n`、`TEST-`、`PGG-` 或舊 LINE 連結。
- 三張回饋截圖皆為本地資產且具有替代文字。
- 所有外部連結具備安全屬性。
- CSS 包含手機斷點、最小文字與觸控尺寸、無固定底部遮擋。

人工驗證須涵蓋 1440px、768px、390px 及 320px 寬度，確認無水平溢出、導覽可用、圖片完整、文字可讀、無瀏覽器主控台錯誤。
