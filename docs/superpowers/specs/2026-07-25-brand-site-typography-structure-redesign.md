# 品牌型網站字級與 HTML 結構重整規格

## 目標

將現有四頁靜態網站從單頁銷售感改為完整品牌網站。保留既有品牌文字、AI 圖片、送禮流程與法務資訊，但重新建立清楚的內容責任、語意結構、字級階層與閱讀密度。

## 已確認問題

1. 上次只更新 `styles.css`，HTML 仍引用 `styles.css?v=20260725-5`，導致新版 HTML 可能套用瀏覽器快取的舊 CSS。
2. 舊 CSS 的卡片規則與新版章節結構混用，造成編號壓住標題、第三項落單、大量空白框等問題。
3. 桌機標題使用 `clamp(34px, 4vw, 52px)`，在寬螢幕上與內文形成過大的視覺落差。
4. `.story-section`、`.chapter-*`、`.feature-list` 等規則責任重疊，讓同一內容型態在不同頁面呈現不一致。
5. 首頁承擔過多「促銷卡片」語言，缺少品牌觀點、產品事實、證言與行動區之間的節奏差異。

## 資訊架構

### 首頁 `index.html`

首頁是品牌與產品介紹，不是價格型銷售頁。內容順序維持：

1. 品牌封面與核心主張
2. 家長困惑
3. 指南的品牌觀點與三項價值
4. 製作方法
5. 客製資料與隱私
6. 送禮入口
7. 實際交付內容
8. 價值比較
9. 使用後的轉變
10. 真實家長證言
11. 品牌結語與行動

每一主題只出現一次。相同主張若在同頁重複，保留最完整的一處，其餘改成簡短銜接，不重複堆疊 CTA。

### `gift.html`

只負責說明送禮方案、購買後收到的內容、交付方式、兌換碼與聯絡入口，不重複首頁的完整品牌故事。

### `navigator.html`

只負責說明導航者的角色、服務邊界與專業方法，不重複送禮方案或長篇產品比較。

### `refund.html`

只負責交易、交付、紙本發票、退款與聯絡政策。語氣清楚可信，不使用促銷式標題。

## HTML 結構

1. 四頁保留完整 `header > nav`、單一 `main`、`footer`。
2. 首頁用一個品牌故事容器包住 11 個有明確 `aria-labelledby` 的語意 `section`。
3. 章節內只使用必要的 `header`、`figure`、內容群組、`ul/ol`、`blockquote` 與 CTA 群組。
4. 將視覺名稱與內容責任分開：
   - `.section-shell`：寬度與上下節奏。
   - `.editorial-layout`：雙欄圖文排列。
   - `.fact-list`：短事實條目。
   - `.process-steps`：有順序的方法。
   - `.proof-gallery`：真實截圖。
   - `.action-group`：僅用於真正需要行動的位置。
5. 不以空白卡片撐高版面，不用固定高度容納短文。
6. 純靜態 HTML 不引入 JavaScript include 或建置框架。四頁必要的導覽與頁尾標記可重複，但以自動測試確保文字、連結與順序一致。

## 視覺與字級

### 桌機

- 內容最大寬度：`1180px`；寬螢幕不再隨 viewport 無限放大。
- 內文：`18–20px`，行高 `1.65–1.75`，每行約 `45–70` 個中文字元。
- 首頁封面標題維持現有比例。
- 章節標題：`36–46px`，不再使用 `4vw` 放大到 52px。
- 條目標題：`20–23px`；說明文字不得低於 `17px`。
- 短資訊使用緊湊列或 2×2 fact grid，內容高度由文字決定。
- 圖片與文字互為主從；方法、資料、交付等資訊型章節，文字權重高於插圖。

### 手機

- 單欄連續閱讀；圖片與文字依敘事決定順序。
- 章節標題 `30–38px`，內文不低於 `17px`。
- 所有條目回到單欄，不出現橫向溢出、重疊編號或截斷。
- 按鈕至少 `52px` 高，表格維持可橫向捲動。

## 品牌質感原則

1. 深夜藍只用於封面、品牌轉場與結尾；正文以象牙白、紙白和少量暖灰建立編輯感。
2. 珊瑚與綠色只用於行動和狀態，不把每個資訊框都做成促銷元件。
3. 三項價值採編輯式直列，不使用「兩格加一個落單」的卡片排版。
4. 四步方法可使用 2×2，但高度由內容決定，編號放在獨立欄位，不與文字重疊。
5. 真實家長截圖保持原比例與可信度，不旋轉、不過度裝飾。
6. AI 圖保留故事內容，可調整裁切、位置與顯示尺度。

## 快取與發布

1. 所有公開頁同步將樣式版本更新為新的唯一版本。
2. 測試必須驗證四頁引用相同版本，且版本與前一版不同。
3. GitHub Pages 部署後，以無快取請求確認公開 HTML 與 CSS 均為最新版本。

## 驗收標準

1. 在約 `1920×1080`、`1280×800`、`375×844` 三種尺寸檢查首頁。
2. 不得有編號壓字、第三張孤立卡片、大面積無意義空框或橫向溢出。
3. 每個章節的標題、完整內容與圖片保持在同一語意章節。
4. 四頁的導覽、頁尾、按鈕、字級與色彩遵循同一設計系統。
5. 首頁完整保留 11 張既有圖片與家長證言。
6. 所有既有內容、無障礙、隱私與 GitHub Pages 測試通過。
