# LINE 支援入口精簡設計

> 本文件已由 `2026-07-26-line-self-service-and-navigator-growth-design.md` 取代。官方 LINE 是自助購買與交付流程入口，不應被定義為只處理例外的客服管道。

## 目標

讓網站優先協助訪客自行理解、判斷與完成下一步，降低一人公司不必要的 LINE 諮詢量；LINE 只作為實際交易或例外狀況的人工處理管道。

## 設計原則

- 導覽列與頁尾不再把 LINE 當成全站主要入口。
- 首頁的主要行動只引導閱讀指南或查看送禮方式。
- 導航者直接填寫申請表，不在表單旁增加「有疑問先問 LINE」。
- 送禮頁的申請條件直接寫清楚，不要求使用者先詢問。
- 目前尚未有線上結帳，因此方案購買、十份以上需求仍保留 LINE，避免建立無法完成的購買承諾。
- 售後、退款、資料更正與交付異常仍在專門的服務說明頁提供 LINE 與 Email。

## 送禮頁保證區塊

- 移除 eyebrow「安心送出」。
- 標題改為「購買前，請先確認孩子的出生資料」。
- 內文直接說明孩子出生時間必須可以確認，建議誤差不超過 30 分鐘；無法確認時請勿購買。
- 移除 LINE 按鈕。

## 驗證

- 公開頁面導覽列與頁尾不得再出現官方 LINE。
- 首頁與導航者頁不得出現 LINE 行動按鈕。
- 送禮頁保證區塊不得含 eyebrow、LINE 連結或「客服陪伴」。
- 送禮方案的實際購買入口、十份以上需求與服務說明頁的例外處理仍可使用 LINE。
- 所有既有無障礙、內容、版面與部署測試必須通過。
